# Instruksi AI Harness - Proyek Lab Pemrograman (Uji Pasar 5 Produk)
1. Tujuan: Menguji minat pasar (product-market fit) terhadap 5 kandidat produk digital kampus melalui landing page dan pelacakan metrik traffic/klik.
2. Stack: HTML5, TailwindCSS, dan JavaScript murni.
3. Tracking: Setiap tombol pada 5 produk wajib mencatat jumlah klik minat dan sumber traffic (UTM).
4. Keamanan: Dilarang menaruh API Key di dalam kode publik.
